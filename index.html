SISTEMAS CAUSALES

La salida depende únicamente de los valores presentes y pasados de la señal de entrada.

\[ y(t)=x(t)+x(t-1) \]

Análisis

La salida utiliza:

  • \(x(t)\): valor presente.
  • \(x(t-1)\): valor pasado.

No utiliza valores futuros de la entrada.

✓ SISTEMA CAUSAL

SISTEMAS NO CAUSALES

La salida depende de uno o más valores futuros de la señal de entrada.

\[ y(t)=x(t+1) \]

Análisis

Para calcular la salida en el instante \(t\), se necesita conocer la entrada un segundo después.

\[ x(t+1):\text{valor futuro} \]

✗ SISTEMA NO CAUSAL

SISTEMAS SIN MEMORIA

Un sistema es sin memoria cuando su salida en un instante depende únicamente del valor actual de la entrada.

\[ y(t)=T\{x(t)\}=f(x(t)) \]

Ejemplo: Sistema sin memoria

\[ y(t)=3x(t) \]

La salida depende exclusivamente de la entrada en el mismo instante de tiempo.

No necesita valores pasados ni futuros de la señal.

✓ SISTEMA SIN MEMORIA

SISTEMAS CON MEMORIA

Un sistema tiene memoria cuando su salida depende de valores de la entrada correspondientes a otros instantes de tiempo.

\[ y(t)=x(t)+x(t-1) \]

Ejemplo: Sistema con memoria

La salida depende de:

\[ x(t):\text{valor presente} \] \[ x(t-1):\text{valor pasado} \]

Para calcular la salida actual, el sistema necesita información de un instante anterior.

✓ SISTEMA CON MEMORIA

SISTEMAS ESTABLES

Un sistema es estable BIBO si toda entrada acotada produce una salida también acotada.

\[ |x(t)|\leq M_x < \infty \] \[ \Downarrow \] \[ |y(t)|\leq M_y < \infty \]

Ejemplo: Sistema estable

\[ y(t)=2x(t) \]

Si la entrada está limitada por:

\[ |x(t)|\leq 5 \]

Entonces la salida cumple:

\[ |y(t)|=|2x(t)|\leq 10 \]

✓ SISTEMA ESTABLE

BIBO: entrada acotada, salida acotada.

SISTEMAS INESTABLES

Un sistema es inestable BIBO cuando existe al menos una entrada acotada que produce una salida no acotada.

\[ y(t)=t\,x(t) \]

Ejemplo: Sistema inestable

Consideramos una entrada constante y acotada:

\[ x(t)=1 \]

La salida será:

\[ y(t)=t(1)=t \]

A medida que el tiempo aumenta, la salida crece sin límite.

✗ SISTEMA INESTABLE

EJEMPLO: SISTEMA CAUSAL

Analizamos una salida que depende de los valores presentes y pasados de la entrada.

\[ y(t)=x(t)+x(t-1) \]
● Entrada x(t) ● Salida y(t)

La salida utiliza la entrada actual y la entrada retrasada un segundo. No necesita información futura.

✓ SISTEMA CAUSAL

EJEMPLO: SISTEMA NO CAUSAL

Observamos un sistema cuya salida necesita conocer un valor futuro de la entrada.

\[ y(t)=x(t+1) \]
● Entrada x(t) ● Salida y(t)

La salida aparece un segundo antes que la entrada, porque depende de x(t+1), es decir, de un valor futuro.

✗ SISTEMA NO CAUSAL

EJEMPLO: SISTEMA SIN MEMORIA

Comprobamos un sistema cuya salida depende únicamente del valor actual de la entrada.

\[ y(t)=2x(t) \]
● Entrada x(t) ● Salida y(t)

La salida tiene el doble de amplitud que la entrada, pero conserva el mismo intervalo temporal.

✓ SISTEMA SIN MEMORIA

EJEMPLO: SISTEMA CON MEMORIA

Analizamos un sistema que utiliza información de un instante anterior.

\[ y(t)=x(t)+x(t-1) \]
● Entrada x(t) ● Salida y(t)

La salida combina la entrada actual con una versión retrasada un segundo. Por ello, depende del pasado.

✓ SISTEMA CON MEMORIA
